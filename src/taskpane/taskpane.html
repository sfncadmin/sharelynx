Policy Admin

Edit policy in SharePoint →

Manage the SFNC_ShareLinks_Policy list on your SharePoint root site. Create the list with two text columns: Title (setting key) and SettingValue. Changes take effect after the next sign-in.

Supported keys: allowAnonymousLinks, adminOnlyAnonymousLinks, allowOrganizationLinks, allowSpecificPeopleLinks, defaultScope, defaultType, defaultExpDays, adminGroupIds (comma-separated group IDs or display names), homeAttribute (Exchange custom attribute slot 1–15 holding each user's home path; default 10), spHome:<group> (home path for a group, e.g. VSTH Files/Documents/PROJECTS).

Home paths: per-user attribute wins over group rules. Set per user with e.g. Set-Mailbox user -CustomAttribute10 "VSTH Files/Documents". Members land there when opening the SharePoint tab and can navigate back up to all sites.
