ShareLynx

OneDrive and SharePoint sharing, built into Outlook.

  • Browse OneDrive and SharePoint files without leaving Outlook
  • Create sharing links with audience, permission, and expiration controls
  • Manage and revoke every link you've shared
  • Convert oversized attachments to sharing links on the fly
  • Tenant-wide policy via a SharePoint list, no code changes needed
View on GitHub Setup guide

Deploy to your tenant

  1. Fork or clone the repo
  2. Run .\setup\ShareLynx_Entra_Setup.ps1 -MultiTenant and enter your hosting URL
  3. Host the files (GitHub Pages, Azure Static Web Apps, any HTTPS host)
  4. Grant admin consent and upload manifest.xml in M365 admin center

Works in classic Outlook for Windows, new Outlook, and Outlook on the web. No per-machine installs, no backend, no stored data.
