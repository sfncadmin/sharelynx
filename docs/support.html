ShareLynx Support

ShareLynx is an Outlook add-in for creating and managing OneDrive and SharePoint sharing links.

Setup Help

Start with the deployment guide. It covers app registration, admin consent, manifest upload, and common Outlook cache issues.

Common Issues

If sign-in fails, confirm that admin consent was granted and that the app registration includes the redirect URL for your hosted copy of ShareLynx.

If Smart Alerts do not appear on send, confirm the add-in is deployed to an Outlook client that supports the Mailbox 1.12 requirement set.

If tenant policy does not apply, confirm the ShareLynx_Policy list exists on the configured SharePoint site and has Title and SettingValue columns.

Security Notes

ShareLynx runs as a static client-side add-in. It does not send files or tokens to a ShareLynx server. Microsoft Graph requests are made directly from Outlook using the signed-in user's delegated permissions.
